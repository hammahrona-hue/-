这一讲到底学什么？先定位

对应视频 00:22 ~ 33:20 的开场 & 「学习」的复习

先听个故事

想象你走进一家「学习」主题的博物馆。一楼是「学习分类馆」——四位馆长（奥苏贝尔、加涅、阿瑟雷伯、我国学者）各自用自己的标准把「学习」这件事分了类。二楼是「学习理论馆」，有四个展厅：行为、认知、建构、人本。这一讲，老师只带我们逛完一楼，再进二楼第一个展厅「行为主义」，看两位大佬的实验：桑代克的猫和巴甫洛夫的狗。至于斯金纳的小白鼠和班杜拉的宝宝，老师原话「明天讲」——所以这本手册里也不会出现它们的内容，别去别处硬补。

0.2先复习：什么叫「学习」？

个体（人、动物）在一定条件下，凭借经验或练习，产生的行为或行为潜能的比较持久的变化。

说人话

三个词就够：练出来的（不是天生的）、变了（行为或者「以后会这么做」的可能性）、持久（不是一时的）。

注意「行为潜能」四个字：你今天上课后心里更爱一个人了但没表现出来，这也是学习——所以老师说「学习不一定能观察到」。考判断：「学习是可观察的行为变化」→ 错。

哪些不是学习？
膝跳反射 ✕ 本能疲劳后动作变形 ✕ 生理暗适应 ✕ 生理背诵唐诗 ✓ 学习

一句话记：天生就会的、身体累出来的，都不算学习。

0.4人和动物的学习有什么区别？

人的学习靠语言和复杂的认知（思维）；动物只是训练出「刺激→反应」。

真题 · 2024 四川下

阿杰通过书籍和网上教程学会了编程，还和同学讨论、参加比赛；阿杰养的小狗经过多次训练，学会了听见铃声就到饭碗前等食物。下列说法正确的是：

A. 阿杰的学习是通过条件反射获得的　B. 阿杰和小狗的学习方式没有本质区别
C. 阿杰和小狗都通过模仿同伴学习　D. 阿杰的学习依赖于语言和复杂的认知能力

老师解法
  1. 先读题，再判断考点：一人一狗放在一起 → 考「人和动物学习的区别」。
  2. 阿杰用了书籍、教程、讨论 → 全是语言；理解逻辑 → 思维（认知过程里最高级的那个）。
  3. 小狗：铃声（别人给的）→ 到碗前等（它做的），刺激在前、反应在后，多次训练建立联结，这才是条件反射。所以 A 错（阿杰不是）、B 错（有本质区别）、C 错（谁也没模仿榜样）。
  4. 答案 D。
记住这个做题总规矩

老师这节课反复说的两句话，后面每一站都会用到：

① 「刺激是别人给的，反应是他自己做的。」——铃声是别人给的，流口水是狗做的。

② 「一道题上来，第一件事读题，第二件事判断它考哪个知识点。」不许加戏、不许自己延伸题目没说的内容。

自己考自己
学习的定义里，哪四个字说明「学习不一定看得见」？
「行为潜能」。态度、认知、情感的变化可能不表现出来，但也是学习。
膝跳反射、暗适应为什么不算学习？
它们是本能 / 生理变化，不是凭借经验或练习产生的。
人和动物学习的本质区别是什么？
人依赖语言和复杂的认知（思维）；动物是单纯的刺激—反应训练。

奥苏贝尔：两把尺子量一次学习例子题为主

对应视频 00:43 ~ 12:04 · 幻灯片 S001 ~ S004

先听个故事

你家小侄子学会了「二八十六」。奥苏贝尔走过来，只掏出两把尺子量他：

第一把尺子问：这东西是谁给的？是老师把结论直接塞给他（接受），还是他自己在数积木时琢磨出来的（发现）？

第二把尺子问：他懂了没？他知道「二八十六」和「八二十六」其实是一回事，说明新知识和他脑子里旧的东西接上了（有意义）；他只是像念咒一样背下来，脑子里啥也没接上（机械）。

两把尺子各量各的，互不干涉。所以一共能量出 4 种组合——就像身高和体重，高的人不一定重。

1.2 / 1.3第一把尺子：接受 vs 发现

接受学习

内容以结论方式呈现，老师讲、学生接。
效率高（成体系、有组织、有目的），所以它是学生学习的主要方式。
缺点：忽视学生主动性 / 主体性。

VS

发现学习

内容不直接呈现，学生独立思考、探索、发现。
效率低（慢），但能发挥主动性、以学生为主体。

说人话

就问一句：结论是别人端上桌的，还是你自己下厨做出来的？端上桌 = 接受；自己做 = 发现。中间还有一种「有指导的发现」：导师指点着你写论文、老师指导着你做实验——像有人在旁边报菜谱、你自己动手。

1.4 / 1.5 / 1.6第二把尺子：机械 vs 有意义

旧知识 = 你已有的经验；新知识 = 接下来要学的材料。能用旧的理解新的，就是建立了联系。

说人话

有意义 = 接上了，理解了。像你学过三角形，现在学四边形，一看「四边形能拆成两个三角形」——这个「二倍关系」是知识本来就有的联系，你用旧的懂了新的。

机械 = 没接上，不理解。脑子里有旧经验，但看新材料就是看不懂，只能硬背。

小孩先背「苹果香蕉梨」、先背单词，后来才慢慢懂——所以是先机械，后有意义。

最大的坑：人为编的联系不算

有意义学习要求联系是「非人为、实质性」的——知识本身就有的联系。你为了背圆周率编「山巅一寺一壶酒」（3.14159），这个联系是你硬编的，数字本身没这意思。所以编口诀、谐音记单词、打油诗背圆周率，考试一律不算有意义学习，归到机械。老师原话：「它可以是意义识记，但不是有意义学习。」

⚠ 别把「意义识记」（记忆那一章的词，允许人为赋予）和「有意义学习」（奥苏贝尔的词，必须非人为）混起来。

1.7 ~ 1.10四句必背结论

考试写这些词
  1. 两个维度互不依赖、彼此独立：接受可以机械也可以有意义，发现也一样，可以交叉。
  2. 四种学习无高低之分（发现学习不比接受学习高级）。
  3. 奥苏贝尔提倡 有意义的接受学习。（对比：后面会学布鲁纳，他强调发现学习——每个学者提倡的不一样。）
  4. 顺序：先机械、后有意义。
记忆钩子

「谁给的？懂了没？」——六个字，两把尺子。再加一句「奥苏爱接受，布鲁纳爱发现」。

考场上怎么选

判断题考定义：「接受学习即机械学习，发现学习即意义学习」→ 错（互不依赖）。

例子题（为主）两步走：第一步看「谁给的」→ 接受/发现；第二步看「懂不懂」→ 机械/有意义。题干问「有意义的接受」就要两个条件同时满足。

真题 · 2023 四川上 · 判断
小明听生物老师的讲解，理解了生态系统的食物链和食物网两个概念之间的关系。小明的学习属于发现学习。
第一步「听老师讲解」→ 别人给的 → 接受，所以「发现」直接判错。第二步「理解了」→ 有意义。完整说法：有意义的接受学习。答案 B
真题 · 单选
幼儿能将乘法口诀背得滚瓜烂熟，但可能不知道二八十六和八二十六之间的关系。这种学习属于（　）。
第一步乘法口诀是外面给的 → 接受。第二步不知道关系 → 不理解 → 机械。答案 C：死记硬背就是机械的接受。
真题 · 2020 四川下 · 单选（老师说 C 是唯一迷惑项）
下列哪种学习属于有意义的接受学习？
A 科学家自己探索 → 发现（还是独立发现），排除。B 迷宫不是别人给的 → 发现，排除。C 圆周率是别人给的 → 接受 ✓；但打油诗是人为赋予的联系 → 不算有意义 → 排除。这是陷阱。D 听讲座 → 接受；理解关系 → 有意义。答案 D。
自己考自己（先说出来，再点开）
奥苏贝尔的两把尺子分别问什么？各自分出哪两类？
① 学习方式（谁给的）：接受 / 发现；② 新旧知识关系（懂了没）：机械 / 有意义。
「用谐音记单词」为什么不算有意义学习？考试归哪类？
因为联系是人为赋予的，不是非人为、实质性的。归机械学习。
接受学习和发现学习哪个高级？奥苏贝尔提倡哪种？
无高低之分。奥苏贝尔提倡有意义的接受学习（布鲁纳才强调发现学习）。
接受学习效率高还是低？缺点是什么？
效率高（是学生学习的主要方式），缺点是忽视学生的主动性/主体性。

加涅：一张榜单 + 一座梯子老师说最有挑战

对应视频 12:25 ~ 16:50 · 幻灯片 S005 ~ S009

先听个故事

加涅是个爱分类的收藏家，他给「学习」做了两份清单，但两份清单的性质完全不同：

第一份是「战利品榜单」——学完之后你手里拿到了什么？他数出 5 样：一张会说话的嘴（言语信息）、一颗会算的脑（智慧技能）、一套管自己的方法（认知策略）、一颗有态度的心（态度）、一双会动的手（动作技能）。榜单上的 5 样东西是并列的，没有谁比谁高。

第二份是「爬梯子」——学习有难有易，他画了 8 级台阶，必须从低到高：从最简单的「听到信号就有反应」，一直爬到最难的「解决复杂问题」。

考试就爱考：榜单不分高低，梯子有顺序。

2.1榜单：学习结果分类（5 类，无高低）

口诀：颜值太动人

颜（言语信息）值（智慧技能）太（态度）动（动作技能）人（认知策略——「人」取「认」的音）

类别说人话题目里长这样
言语信息能说出来的事实、知识背出一首古诗、说出一个定义
智慧技能用概念、规则去办事、解题（辨别/概念/规则/问题解决都归它）用公式解题、把马和狗分类
认知策略管自己怎么学的方法和技巧「运用归类法记忆其他单词」——重点在方法、调控
态度情感倾向，喜欢/敬佩/热爱参观博物馆后产生热爱之情；看电影产生敬佩之情
动作技能骨骼肌肉层面的动作体操、广播体操

2.2梯子：学习水平分类（8 级，从低到高）

口诀：心机所言，别念这题

心信号 → 机刺激-反应 → 所连锁 → 言言语联想 → 别辨别 → 念概念 → 这规则 → 题问题解决（高级规则）

说人话：8 级台阶一个个讲
  1. 信号学习：刺激在前，反应在后。铃一响，狗流口水。（S→R）
  2. 刺激-反应学习：反应在前，刺激在后，而且只有一个动作。你举手（一个动作），老师表扬你。（R→S）
  3. 连锁学习：一连串动作。用钥匙开锁 = 掏钥匙 → 对准锁眼 → 扭——三个动作串起来。体操也是。
  4. 言语联想学习：连成串的是语言，不是动作。词一、词二、词三连成一句话。
  5. 辨别学习：分得清。区分形状大小，区分两个特别像的单词。
  6. 概念学习：比辨别更进一步，抓住共同本质特征（所有的鸟都有什么特点），而且加涅认为学会的标准是能运用概念去识别、归类（哪个是马、哪个是狗）。
  7. 规则学习：概念和概念的关系——公式、定理、原理，学会的标准是能用公式解题、用原理指导行为。
  8. 问题解决（高级规则）：题目复杂、要组合多个规则才能解决，一个规则不够用。
坑 ① 「刺激-反应学习」和行为主义的 S-R 不是一回事

加涅的第 2 级「刺激-反应学习」强调反应在前；而行为主义说的「刺激-反应联结（S-R）」没有箭头、不分先后。老师反复说：「分开记，不要联系。」

坑 ② 加涅只看「最终学习结果」

你学了「质量」这个词，能背出来 ≠ 学会了；能用这个概念才算。学古诗能背出来就算达到结果（那是言语信息）。题干出现「下定义」三个字 → 就是定义性概念，抓关键词做题。

考场上怎么选

① 考顺序：学习水平 8 级从低到高排序 —— 背口诀。② 考归类：给情境判断属于 5 类结果的哪一类 / 8 级水平的哪一级。

真题 · 2024 四川上 · 单选（讲义答案曾校对错，老师课上改为态度）
通过参观红色文化博物馆，听讲解员讲中华文明的起源，小学生们产生了对祖国的热爱之情。根据加涅的分类，学生进行了（　）的学习。
看落脚点：「产生热爱之情」——情感问题，没有任何「解决问题」的动作。答案 A 态度。老师提醒：别迷信答案，讲义里那版（看电影产生敬佩之情）也选态度（B）。
真题 · 单选（很多同学错）
教师向学生随机呈现一个词表并要求记住，学生学会了按蔬菜、肉类、水果等对单词进行归类组织，并运用该方法记忆其他单词。根据加涅的观点这属于（　）。
大意漏神的地方：前面看到「归类」就想到概念/智慧技能。看后半句：「运用该方法记忆其他单词」——这是记忆方法、技巧、调控 → 认知策略。答案 C。
真题 · 单选
学生学习体操动作，这种学习属于（　）。
体操不可能只有一个动作，一定是多个动作连成串 → 连锁。排除：信号是刺激在前；辨别是区分；言语联想是语言层面；体操是骨骼肌肉层面。若有「刺激-反应」选项也不选（它只有一个动作）。答案 B。
自己考自己
加涅两种分类，哪个有高低顺序，哪个没有？
学习结果 5 类无高低；学习水平 8 级从低到高。
用钥匙开锁、举手被表扬、听铃流口水，各属于哪一级？
连锁学习（一串动作）；刺激-反应学习（一个动作，反应在前）；信号学习（刺激在前）。
概念学习学会的标准是什么？
不只知道本质特征，还要能运用概念去识别、归类。
背口诀：颜值太动人 / 心机所言别念这题，分别对应什么？
言语信息、智慧技能、态度、动作技能、认知策略 / 信号、刺激-反应、连锁、言语联想、辨别、概念、规则、问题解决。

另外三种分法 + 实战演练识记

对应视频 16:31 ~ 33:20 · 幻灯片 S005 ~ S014

先听个故事

博物馆一楼还剩两位小馆长。阿瑟雷伯只关心一件事：你学的时候脑子亮着灯没？灯亮着、你知道自己正在记——叫外显学习；灯没亮、不知不觉就会了（比如听歌听多了自然会唱）——叫内隐学习。

然后是我国学者（冯忠良、潘菽），他们按「学什么内容」分，都有「知识」和「技能」两样，区别只在多加了什么。老师说这块四川还没考过，多选题看到谁就匹配谁，有个印象即可。

3.1阿瑟雷伯：按意识水平

内隐学习

无意识、不知不觉。没特意记，也不知道自己在记，后来发现记住了。

VS

外显学习

先听个故事：小阿尔伯特

一百年前，有个叫阿尔伯特的小宝宝，特别喜欢毛茸茸的小白鼠，抱着玩得很开心。心理学家华生和助手躲在旁边，每当宝宝一摸小白鼠，就「咣」地敲一下大锣，把他吓得哇哇哭。一次、两次、三次……后来宝宝一看到小白鼠就害怕；再后来，所有带白毛的东西——兔子、皮大衣、圣诞老人的胡子——他都怕。恐惧像水一样泛开了，所以这个实验叫恐惧泛化实验。

6.9 ~ 6.12三条学习公律（重点展开）

6.9① 准备律：先有「想学」

说人话

进入学习之前，学习者做好的预备性反应 / 预备定势——可以是生理的（猫饿了才想觅食），也可以是心理的（老师提前告诉你今天讲到哪，你心里有准备、想听懂好上岸）。不管哪种，落脚点都是「想学」这个动机——所以准备律属于动机范畴。

有准备 + 让他学 → 满意；有准备 + 不让他学 → 烦恼；没准备 + 硬让他学 → 也烦恼。启示：不能搞突袭，上课前吃好饭、上好厕所、做好预习。

最容易错的细节：两个角度分开看

教材原句：「桑代克讲的准备不是学习前的知识准备或成熟方面的准备，而是学习者在学习开始时的预备定势，属于动机范畴。」

定义角度（判断题问「准备律 = 知识准备/成熟」）→ 不等同，判错。
例子角度（题干说预习、复习旧知、查资料、预设问题）→ 这些都能激发学习动机，所以都算准备律。老师原话：「不是说知识准备达不到准备律的效果，只是桑代克没从这个角度说。」

教材出处补充（S032）：准备工作包括两方面——身心基础（学武术先看身体发育、四肢关节是否灵敏）和学习动机（复习上次所学、查有关资料，以便对新教材产生兴趣）。都是为了调动学习积极性。

6.11② 练习律：用进废退

说人话

已经连上的线，反复用就变粗（应用律：常用 → 联结增强），不用就变细（失用律：不练 → 联结减弱）。猫反复开笼子才熟练；你反复做题才一看就会。启示：学习过程中和结束后都要不断练习。

题目里长这样：「算不同类型的题」「每天听说必不可少」——只强调练了很多次，没提反馈结果。

6.12③ 效果律：反馈决定一切（最重要）

老师自己的故事

老师去学车，教练从来不说她练得对不对，越练越懵；后来她到处问、拿到反馈，进步飞快。所以光有准备、光练，不告诉你对错，你成功不了——这就是效果律最重要的原因，另外两条都从属于它。

说人话

行为之后得到的反馈：满意的结果 → 行为频率上升（满意律）；烦恼的结果 → 行为频率下降（烦恼律）。猫逃出去吃到鱼（满意），下次还按；逃出去啥也没有甚至是坨狗屎，就不按了。

启示：让学生的学习达到自我满意的积极结果，防止一无所获的消极结果。表扬、鼓励、情绪价值都给上。

题目里长这样：表扬 / 批评 / 鼓励 / 成绩好坏 / 感受乐趣——只要是对行为结果的反馈，就是效果律。

7.3 / 7.4先搞懂两个词：无条件反射 vs 条件反射

无条件反射 = 先天、本能

无条件刺激（US）→ 无条件反应（UR）
吃东西流口水（不流口水就噎死了）、气流进眼睛就眨眼、敲膝盖腿弹起来。不用学，天生就会。

VS

条件反射 = 后天、学来的（又叫信号反射）

条件刺激（CS）→ 条件反应（CR）
听到上课铃就进教室——刚出生的孩子可不会这样，是后天学的。（「闹钟响就起床」有争议：被吵醒是一回事，建立闹铃意识是另一回事；考的可能性不大。）

说人话

判断先天后天就问自己一句：「我天生就会对这个东西有反应吗？」所有的狗天生听到铃就流口水吗？不会 → 后天 → 条件。

「反应」和「反射」两个词常混用——产生了无条件反应，就代表有了无条件反射。别死掐。

7.6实验四步：铃声是怎么「变身」的

故事：闺蜜与流量

老师的比方特别好记——食物和铃声是一对闺蜜，总是一起出现。一起出现的次数多了，铃声「碰瓷」食物、蹭到了流量；后来铃声单独出现，狗心里想「你来了，那她（食物）也马上到」——于是流口水。

坑 ①：巴甫洛夫是「刺激在前、反应在后」

不管铃声还是食物，都是先给刺激，狗再反应——S → R。这和桑代克（R → S）正好相反，第 9 站要考。

7.8怎么结合才有效？口诀：要么先中性，要么和中性同时

说人话：铃声是「预告」

铃声的作用是预告开饭——像养鸡场一打铃鸡就聚过来。所以必须先铃声、紧接着食物（紧接着！隔半天狗就不知道它俩有关系了），或者铃声和食物同时出现。

先食物、后铃声行不行？不行——狗都吃完、流完哈喇子了，你再摇铃，「咋的，让我跳个舞消化一下？」预告放在饭后就没意义了。

翻译成术语：中性刺激在前，后面可以接无条件刺激（一级）或条件刺激（二级）；或者中性刺激与之同时呈现。所以口诀只有一句：要么先中性，要么和中性同时。

7.9 ~ 7.12一级 vs 二级（高级）条件作用：看它「碰瓷」了谁

一级条件作用

中性刺激跟无条件刺激（先天就有感觉的东西，如食物）结合建立。

VS

二级 / 高级条件作用

中性刺激跟条件刺激（后天才有感觉的东西，如铃声）结合建立。

说人话：替身文学

二级里，铃声替了食物的班——以前是食物带着别人（铃声）出道，现在是铃声带着别人（灯光）出道，铃声顶替了食物的岗位。教材那句绕口的话「在条件作用形成以后，条件刺激可以像无条件刺激一样诱发反应，条件刺激似乎成了一种『替代性』的无条件刺激」——以及拔高判断「中性刺激一旦成为条件刺激，就可以作为无条件刺激」——里面的「作为」就是「替代」的意思。

能不能建三级、四级？只要狗没问题就可以，但三级勉强、四级更难。

巴甫洛夫三个考点，一口气记
  1. 实验流程：食物→铃声→灯光，每次「结合 N 次，然后单独起作用」。
  2. 建立顺序：要么先中性，要么和中性同时。
  3. 替代：高级条件作用中，条件刺激替代了无条件刺激（中性一旦成为条件，就可以作为无条件）。

7.13 / 7.14老师的两步做题法（后面所有巴甫洛夫题都用）

考场上怎么选
  1. 分清刺激和反应：外界给的 = 刺激；个体（人/狗）做出来的 = 反应。题目问的是「铃声」还是「流口水」？先把反应/反射类选项排掉。
  2. 分清先天和后天：天生就有感觉 = 无条件；后天学来的 = 条件。问自己「我天生对它有反应吗？」
  3. （拔高）问一级还是高级 → 往上推导：这个刺激是跟谁结合才有的？跟无条件结合 → 一级；跟条件结合 → 高级。

小技巧：条件反射 = 后天学习的结果 → 能判断出是条件反射，就能判断它是「学习」（望梅止渴既是条件反射也是学习，联动了）。

第一 / 第二信号系统：有没有「说话」成语题专场

但人比狗多了一样东西：语言。老师跟你描述一块提拉米苏——咖啡液泡的、上面有蓝莓、微苦带甜——你听完流口水了。这次刺激不是蛋糕本身，而是「话」。靠语言当中介引起的条件反射，叫第二信号系统，人独有——因为狗没有语言。

8.1 ~ 8.3两个信号系统（都是条件反射，都是大脑皮层功能）

第一信号系统

物理性的、具体的条件刺激：声、光、雷、电。
人 + 动物都有。
狗听铃流口水；人听铃回教室坐好。

VS

第二信号系统

以语言为中介的、抽象的条件刺激。
人特有。
语言有几种形式（了解即可，不考多选）：

  • 口头语言：谈虎色变、谈梅生津（谈 = 说）
  • 书面语言：看到「虎」字就害怕
  • 内部言语：一想到测验就焦虑（脑子里在说话，不是图片）
  • 交通语言（有争议，单独记）：司机看到红灯停车——因为从小学过「红灯停」，红灯有了意义
  • 其他：哑语、旗语
说人话

分不清「声光影电」？不要紧，只看有没有「语言」两个字：刺激是通过语言传给你的 → 第二；不是语言传的（一个声音、一个影子、一个图样）→ 第一。

8.4老师的三步判断法

坑 ①：不许加戏

题目没说的你不许延伸！杯弓蛇影里传给他的就是一个影子，有说话吗？没有。你不要在这说「哎呀我大脑里想到太可怕了」——那叫加戏。

判断第一还是第二，看的是刺激怎么传递给他——通过语言，还是通过一个图样。个体自己在那叭叭讲话没用。

坑 ②：典故不一定是第二

「望梅止渴」从字面看：望着梅子流口水，没人说话 → 第一。从典故看：曹操对士兵说「前方有梅林」，士兵口里生津 → 曹老板讲话了 → 第二。所以要看题目具体描述，不是看到典故就选第二。

先听个故事：狗的一生四阶段

还是那条狗。① 它从「对铃声没感觉」到「一听铃声就流口水」——这个从无到有的过程叫获得。② 后来主人只摇铃、再不给饭，摇了很多次……狗也不傻：「你再摇我也不流了，不跟你玩了」——反应越来越弱直到消失，叫消退。③ 有一天主人吹口哨，狗一听「跟铃声挺像」，也流口水了——它分不清两个相似刺激、做了相同反应，叫泛化。④ 主人开始训练：摇铃给饭，吹口哨不给饭，反复多次。狗又聪明了：铃声流、口哨不流——分得清了，对相似刺激做不同反应，叫分化。

9.1 / 9.2获得与消退

获得：无 → 有

条件刺激（铃声）反复与无条件刺激（食物）相匹配，使条件刺激获得信号意义的过程。就是条件反射的建立过程。

VS

消退：有 → 少 → 无

条件反射形成后，条件刺激重复出现多次而没有无条件刺激相伴随，条件反应变弱，最终消失。（光给铃声不给食物。）

9.3 / 9.4泛化与分化

泛化：相似刺激 → 相同反应（分不清）

学会对某一特定条件刺激反应后，其他相类似的刺激也能诱发该反应。
例：一朝被蛇咬，十年怕井绳（蛇和绳分不清）；杯弓蛇影（弓影和蛇分不清）；分不清相似的字；分不清「勇敢」和「鲁莽」。
好处：让学习从一种情境迁移到另一种情境（语文课的高效方法迁到英语课）。

VS

分化：相似刺激 → 不同反应（分得清）

通过选择性强化和消退（铃声给饭、口哨不给），学会对条件刺激和类似刺激做出不同的反应。
例：能分辨「谦让」和「退缩」。
好处：对不同情境做出不同的恰当反应，避免盲目行动。

说人话

泛化 = 「差不多就行」；分化 = 「不一样就得区分」。两者互补：一个帮你把好东西迁过去，一个帮你做恰当区分，合起来学习效果才好。它们都是中性词，不一定是坏事。

考场上怎么选

用「分得清 / 分不清」能做七八成题；剩下的从定义角度更稳：题干出现「相似 / 类似情境 → 相同 / 类似反应」→ 泛化；「经训练后仅对某一个反应」→ 分化。

单选
学生在数学课上学会了端坐在座位上认真做作业，在英语课上学生也做出类似行为。这表明学习行为存在（　）。
相似情境（数学课→英语课）做出类似行为 → 定义角度直接对上泛化。这题用「分不清」反而不好做，用定义更快。答案 B。
单选
经典条件作用理论认为，有机体学会对某一特定的条件刺激做出条件反应以后，类似的刺激也能诱发该条件反应。这一现象称为（　）。
「类似的刺激也能诱发」= 相似刺激相同反应。答案 C。
单选
狗最初对圆形和椭圆形做出同样的反应，经训练后仅对圆形做出该反应，这是条件反射的（　）。
一定要看到后面：「经训练后仅对圆形反应」→ 能分清圆和椭圆了。答案 D。（前半句「同样的反应」是泛化，那是训练前。）

10.1 ~ 10.4溯源拔高：经典性 vs 操作性（S086）

先听个故事

把猫和狗放在一起看：狗是先听到铃（刺激）再流口水（反应），S → R；猫是先按杠杆（反应）再吃到鱼（刺激），R → S。斯金纳后来把「先做动作、再得结果」这种叫操作性条件反射——所以桑代克和斯金纳从性质上都属于操作性，巴甫洛夫是经典性。

但它俩的实质是一样的：都是刺激和反应建立联结（S-R）；不一样的只是建立过程：谁在前谁在后。

幻灯片上的四道判断（S086）
  • 操作性条件反射理论强调行为前的强化 → 错（行为在前，强化在后）
  • 桑代克和斯金纳的学习理论从性质上看都属于操作性条件反射 → 对
  • 经典条件反射的建立过程与操作条件反射的建立过程无根本差异 → 错（S→R vs R→S，有差异）
  • 经典性条件理论和操作性条件理论的实质相同 → 对（都是 S-R 联结）

获得、消退各是什么？消退的操作是？

泛化和分化的解题关键各六个字？

分化是通过什么实现的？泛化对学习有什么好处？

桑代克属于经典性还是操作性？经典与操作实质相同吗？建立过程相同吗？
