奥苏贝尔：两把尺子量一次学习例子题为主

对应视频 00:43 ~ 12:04 · 幻灯片 S001 ~ S004

先听个故事

你家小侄子学会了「二八十六」。奥苏贝尔走过来，只掏出两把尺子量他：

第一把尺子问：这东西是谁给的？是老师把结论直接塞给他（接受），还是他自己在数积木时琢磨出来的（发现）？

第二把尺子问：他懂了没？他知道「二八十六」和「八二十六」其实是一回事，说明新知识和他脑子里旧的东西接上了（有意义）；他只是像念咒一样背下来，脑子里啥也没接上（机械）。

两把尺子各量各的，互不干涉。所以一共能量出 4 种组合——就像身高和体重，高的人不一定重。

1.2 / 1.3第一把尺子：接受 vs 发现

接受学习

内容以结论方式呈现，老师讲、学生接。
效率高（成体系、有组织、有目的），所以它是学生学习的主要方式。
缺点：忽视学生主动性 / 主体性。

VS

发现学习

内容不直接呈现，学生独立思考、探索、发现。
效率低（慢），但能发挥主动性、以学生为主体。

说人话

就问一句：结论是别人端上桌的，还是你自己下厨做出来的？端上桌 = 接受；自己做 = 发现。中间还有一种「有指导的发现」：导师指点着你写论文、老师指导着你做实验——像有人在旁边报菜谱、你自己动手。

1.4 / 1.5 / 1.6第二把尺子：机械 vs 有意义

旧知识 = 你已有的经验；新知识 = 接下来要学的材料。能用旧的理解新的，就是建立了联系。

说人话

有意义 = 接上了，理解了。像你学过三角形，现在学四边形，一看「四边形能拆成两个三角形」——这个「二倍关系」是知识本来就有的联系，你用旧的懂了新的。

机械 = 没接上，不理解。脑子里有旧经验，但看新材料就是看不懂，只能硬背。

小孩先背「苹果香蕉梨」、先背单词，后来才慢慢懂——所以是先机械，后有意义。

最大的坑：人为编的联系不算

有意义学习要求联系是「非人为、实质性」的——知识本身就有的联系。你为了背圆周率编「山巅一寺一壶酒」（3.14159），这个联系是你硬编的，数字本身没这意思。所以编口诀、谐音记单词、打油诗背圆周率，考试一律不算有意义学习，归到机械。老师原话：「它可以是意义识记，但不是有意义学习。」

⚠ 别把「意义识记」（记忆那一章的词，允许人为赋予）和「有意义学习」（奥苏贝尔的词，必须非人为）混起来。

1.7 ~ 1.10四句必背结论

考试写这些词
  1. 两个维度互不依赖、彼此独立：接受可以机械也可以有意义，发现也一样，可以交叉。
  2. 四种学习无高低之分（发现学习不比接受学习高级）。
  3. 奥苏贝尔提倡 有意义的接受学习。（对比：后面会学布鲁纳，他强调发现学习——每个学者提倡的不一样。）
  4. 顺序：先机械、后有意义。
记忆钩子

「谁给的？懂了没？」——六个字，两把尺子。再加一句「奥苏爱接受，布鲁纳爱发现」。

考场上怎么选

判断题考定义：「接受学习即机械学习，发现学习即意义学习」→ 错（互不依赖）。

例子题（为主）两步走：第一步看「谁给的」→ 接受/发现；第二步看「懂不懂」→ 机械/有意义。题干问「有意义的接受」就要两个条件同时满足。

真题 · 2023 四川上 · 判断
小明听生物老师的讲解，理解了生态系统的食物链和食物网两个概念之间的关系。小明的学习属于发现学习。
第一步「听老师讲解」→ 别人给的 → 接受，所以「发现」直接判错。第二步「理解了」→ 有意义。完整说法：有意义的接受学习。答案 B
真题 · 单选
幼儿能将乘法口诀背得滚瓜烂熟，但可能不知道二八十六和八二十六之间的关系。这种学习属于（　）。
第一步乘法口诀是外面给的 → 接受。第二步不知道关系 → 不理解 → 机械。答案 C：死记硬背就是机械的接受。
真题 · 2020 四川下 · 单选（老师说 C 是唯一迷惑项）
下列哪种学习属于有意义的接受学习？
A 科学家自己探索 → 发现（还是独立发现），排除。B 迷宫不是别人给的 → 发现，排除。C 圆周率是别人给的 → 接受 ✓；但打油诗是人为赋予的联系 → 不算有意义 → 排除。这是陷阱。D 听讲座 → 接受；理解关系 → 有意义。答案 D。
自己考自己（先说出来，再点开）
奥苏贝尔的两把尺子分别问什么？各自分出哪两类？
① 学习方式（谁给的）：接受 / 发现；② 新旧知识关系（懂了没）：机械 / 有意义。
「用谐音记单词」为什么不算有意义学习？考试归哪类？
因为联系是人为赋予的，不是非人为、实质性的。归机械学习。
接受学习和发现学习哪个高级？奥苏贝尔提倡哪种？
无高低之分。奥苏贝尔提倡有意义的接受学习（布鲁纳才强调发现学习）。
接受学习效率高还是低？缺点是什么？
效率高（是学生学习的主要方式），缺点是忽视学生的主动性/主体性。
