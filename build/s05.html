先听个故事：小阿尔伯特

一百年前，有个叫阿尔伯特的小宝宝，特别喜欢毛茸茸的小白鼠，抱着玩得很开心。心理学家华生和助手躲在旁边，每当宝宝一摸小白鼠，就「咣」地敲一下大锣，把他吓得哇哇哭。一次、两次、三次……后来宝宝一看到小白鼠就害怕；再后来，所有带白毛的东西——兔子、皮大衣、圣诞老人的胡子——他都怕。恐惧像水一样泛开了，所以这个实验叫恐惧泛化实验。

这个实验伤害很大，小阿尔伯特很早就去世了，父母也不再信任华生，所以没做后续的「消退」实验。它有违伦理，后来的心理学家基本改用动物做实验——这就是为什么下面两站主角是猫和狗。

5.1 ~ 5.5行为主义的身份证

项目内容说人话
创始人华生敲锣吓宝宝的那个
别称联结主义因为它关注「刺激和反应怎么连起来」
联结主义创始人桑代克（不是华生！）两个「创始人」是两个人，考试区分度不大但要记对
研究对象外显行为看得见的行为
研究方法实验法给刺激、看反应
核心思想刺激—反应的联结（S-R）注意：没有箭头，不分谁先谁后
地位第一次革命；第一势力「双料第一」
说人话：为什么是「双料第一」？

心理学刚诞生时研究的是「意识」——你脑子里怎么想的，看不见摸不着，很难验证。行为主义跳出来说：「你们研究的那玩意儿啥也不是！我用实验看得见、测得准，我科学！」——这相当于推翻了前人，所以叫第一次革命；因为它科学、能验证，信的人特别多、队伍特别大，所以叫第一势力。

坑：S-R 没箭头

「刺激—反应的联结」不等于「刺激在前」。它可能刺激在前反应在后（巴甫洛夫），也可能反应在前刺激在后（桑代克）。别被加涅第 2 级的名字带偏，两边分开记。实验里既可以控制刺激（给小白鼠），也可以控制行为（举手就表扬），重点看它们之间怎么建立联系。

钩子

华生创行为，桑代克创联结；只看外在，实验说话；S-R 不带箭头；双料第一。

桑代克：一只饿猫和三条律考 5 次 · 例子题偏爱效果律

对应视频 45:21 ~ 82:24 · 幻灯片 S018 ~ S043

先听个故事：桑代克其人

老师说桑代克是「人丑多读书」的代表：长得不帅，追姑娘老追不上，在爱情上吃了苦，索性一头扎进研究。当时用人做实验有伦理问题，他被逼没招，就用动物——于是成了动物心理学的开创者，还建了美国动物心理学实验室（创始人之一，因为建实验室不可能一个人）。

他 1903 年写了《教育心理学》，1913~1914 年扩成三卷本：《人的本性》《学习心理》《个别差异及其起因》。这是世界公认最早、比较科学又系统的教心专著，也是西方第一本，标志着教育心理学从儿童心理学、普通心理学、教育学里独立出来。所以他是教育心理学之父 / 科学教心鼻祖 / 美国教心奠基人。

两个口诀

桑老三创教心，一生一世，本心差 —— 1903 创《教育心理学》；1913-1914 三卷本；人的本性、学习心理、个别差异。

教心奠基创始父，动物呀！ —— 教心之父/奠基人；联结主义创始人；动物心理学开创者 + 动物心理学实验室创始人之一。

顺带回顾：记忆痕迹衰退说（遗忘理论，也叫自动消退说）的代表人物：桑代克、巴甫洛夫、亚里士多德。

6.4 / 6.5实验：猫开笼取食（饿猫 / 迷笼 / 迷箱实验）

故事继续

一只饿猫（必须饿！不饿它就在笼子里睡大觉，没有「想吃」的动机）被关进笼子，笼子外面放着鱼。它想出去，于是瞎折腾：啃笼子、抓栏杆、到处挠。偶然一次，不小心碰到杠杆，门开了，吃到鱼。再关进去，它还是瞎折腾，但错误越来越少；反复多次后，一进笼子就按杠杆。

老师说迷箱和迷笼只是翻译不同（说「迷箱」时多指后面的斯金纳，但桑代克这个也可以叫迷箱）。

坑：桑代克的实验是「反应在前、刺激在后」

猫先主动按杠杆（反应），再得到食物（刺激）。虽然桑代克说的是「刺激-反应的联结」（没箭头），但从实验看，是 R → S。这一点第 9 站「溯源拔高」要用。

6.6 / 6.7核心观点：学习是什么、怎么建立

考试写这些词
  • 学习的实质：形成联结——刺激与反应的联结（学习即联结）。
  • 联结的建立：通过试误——「盲目尝试 → 逐步减少错误 → 再尝试」反复作用。所以叫试误说。
  • 试误过程受三条学习公律支配：准备律、练习律、效果律。
说人话

学会 = 「按杠杆」和「有鱼吃」在脑子里连上了线。这根线是瞎试、试错、少错一点点搓出来的。

6.9 ~ 6.12三条学习公律（重点展开）

6.9① 准备律：先有「想学」

说人话

进入学习之前，学习者做好的预备性反应 / 预备定势——可以是生理的（猫饿了才想觅食），也可以是心理的（老师提前告诉你今天讲到哪，你心里有准备、想听懂好上岸）。不管哪种，落脚点都是「想学」这个动机——所以准备律属于动机范畴。

有准备 + 让他学 → 满意；有准备 + 不让他学 → 烦恼；没准备 + 硬让他学 → 也烦恼。启示：不能搞突袭，上课前吃好饭、上好厕所、做好预习。

最容易错的细节：两个角度分开看

教材原句：「桑代克讲的准备不是学习前的知识准备或成熟方面的准备，而是学习者在学习开始时的预备定势，属于动机范畴。」

定义角度（判断题问「准备律 = 知识准备/成熟」）→ 不等同，判错。
例子角度（题干说预习、复习旧知、查资料、预设问题）→ 这些都能激发学习动机，所以都算准备律。老师原话：「不是说知识准备达不到准备律的效果，只是桑代克没从这个角度说。」

教材出处补充（S032）：准备工作包括两方面——身心基础（学武术先看身体发育、四肢关节是否灵敏）和学习动机（复习上次所学、查有关资料，以便对新教材产生兴趣）。都是为了调动学习积极性。

6.11② 练习律：用进废退

说人话

已经连上的线，反复用就变粗（应用律：常用 → 联结增强），不用就变细（失用律：不练 → 联结减弱）。猫反复开笼子才熟练；你反复做题才一看就会。启示：学习过程中和结束后都要不断练习。

题目里长这样：「算不同类型的题」「每天听说必不可少」——只强调练了很多次，没提反馈结果。

6.12③ 效果律：反馈决定一切（最重要）

老师自己的故事

老师去学车，教练从来不说她练得对不对，越练越懵；后来她到处问、拿到反馈，进步飞快。所以光有准备、光练，不告诉你对错，你成功不了——这就是效果律最重要的原因，另外两条都从属于它。

说人话

行为之后得到的反馈：满意的结果 → 行为频率上升（满意律）；烦恼的结果 → 行为频率下降（烦恼律）。猫逃出去吃到鱼（满意），下次还按；逃出去啥也没有甚至是坨狗屎，就不按了。

启示：让学生的学习达到自我满意的积极结果，防止一无所获的消极结果。表扬、鼓励、情绪价值都给上。

题目里长这样：表扬 / 批评 / 鼓励 / 成绩好坏 / 感受乐趣——只要是对行为结果的反馈，就是效果律。

6.13 ~ 6.15动物 vs 人，以及评价

考试写这些词
  • 动物的学习是盲目的；人的学习是有意识的（动物的学习无须以观念为媒介）。人进了笼子会先观察、思考，不会像猫一样又啃又咬。——但这也暴露了桑代克早期研究忽视认知、忽视人学习目的性的局限。
  • 三条公律人和动物共有——别因为实验是猫做的就以为人不受影响。
  • 评价：① 教育心理学史上第一个较为完整的学习理论；② 对教育心理学成为一门独立学科有促进意义。
考场上怎么选（老师给的出题角度表 S024）

强化训练 · 易错（很多同学选 D）
桑代克曾做过一个实验：被试蒙上眼睛后练习画 4 英寸长的线段，经过 3000 多次练习毫无进步。对该实验结果最适当的解释是（　）。
