7.3 / 7.4先搞懂两个词：无条件反射 vs 条件反射

无条件反射 = 先天、本能

无条件刺激（US）→ 无条件反应（UR）
吃东西流口水（不流口水就噎死了）、气流进眼睛就眨眼、敲膝盖腿弹起来。不用学，天生就会。

VS

条件反射 = 后天、学来的（又叫信号反射）

条件刺激（CS）→ 条件反应（CR）
听到上课铃就进教室——刚出生的孩子可不会这样，是后天学的。（「闹钟响就起床」有争议：被吵醒是一回事，建立闹铃意识是另一回事；考的可能性不大。）

说人话

判断先天后天就问自己一句：「我天生就会对这个东西有反应吗？」所有的狗天生听到铃就流口水吗？不会 → 后天 → 条件。

「反应」和「反射」两个词常混用——产生了无条件反应，就代表有了无条件反射。别死掐。

7.6实验四步：铃声是怎么「变身」的

故事：闺蜜与流量

老师的比方特别好记——食物和铃声是一对闺蜜，总是一起出现。一起出现的次数多了，铃声「碰瓷」食物、蹭到了流量；后来铃声单独出现，狗心里想「你来了，那她（食物）也马上到」——于是流口水。

坑 ①：巴甫洛夫是「刺激在前、反应在后」

不管铃声还是食物，都是先给刺激，狗再反应——S → R。这和桑代克（R → S）正好相反，第 9 站要考。

7.8怎么结合才有效？口诀：要么先中性，要么和中性同时

说人话：铃声是「预告」

铃声的作用是预告开饭——像养鸡场一打铃鸡就聚过来。所以必须先铃声、紧接着食物（紧接着！隔半天狗就不知道它俩有关系了），或者铃声和食物同时出现。

先食物、后铃声行不行？不行——狗都吃完、流完哈喇子了，你再摇铃，「咋的，让我跳个舞消化一下？」预告放在饭后就没意义了。

翻译成术语：中性刺激在前，后面可以接无条件刺激（一级）或条件刺激（二级）；或者中性刺激与之同时呈现。所以口诀只有一句：要么先中性，要么和中性同时。

7.9 ~ 7.12一级 vs 二级（高级）条件作用：看它「碰瓷」了谁

一级条件作用

中性刺激跟无条件刺激（先天就有感觉的东西，如食物）结合建立。

VS

二级 / 高级条件作用

中性刺激跟条件刺激（后天才有感觉的东西，如铃声）结合建立。

说人话：替身文学

二级里，铃声替了食物的班——以前是食物带着别人（铃声）出道，现在是铃声带着别人（灯光）出道，铃声顶替了食物的岗位。教材那句绕口的话「在条件作用形成以后，条件刺激可以像无条件刺激一样诱发反应，条件刺激似乎成了一种『替代性』的无条件刺激」——以及拔高判断「中性刺激一旦成为条件刺激，就可以作为无条件刺激」——里面的「作为」就是「替代」的意思。

能不能建三级、四级？只要狗没问题就可以，但三级勉强、四级更难。

巴甫洛夫三个考点，一口气记
  1. 实验流程：食物→铃声→灯光，每次「结合 N 次，然后单独起作用」。
  2. 建立顺序：要么先中性，要么和中性同时。
  3. 替代：高级条件作用中，条件刺激替代了无条件刺激（中性一旦成为条件，就可以作为无条件）。

7.13 / 7.14老师的两步做题法（后面所有巴甫洛夫题都用）

考场上怎么选
  1. 分清刺激和反应：外界给的 = 刺激；个体（人/狗）做出来的 = 反应。题目问的是「铃声」还是「流口水」？先把反应/反射类选项排掉。
  2. 分清先天和后天：天生就有感觉 = 无条件；后天学来的 = 条件。问自己「我天生对它有反应吗？」
  3. （拔高）问一级还是高级 → 往上推导：这个刺激是跟谁结合才有的？跟无条件结合 → 一级；跟条件结合 → 高级。

小技巧：条件反射 = 后天学习的结果 → 能判断出是条件反射，就能判断它是「学习」（望梅止渴既是条件反射也是学习，联动了）。

真题 · 2017 四川下 · 理论识记
如果我们想建立某种条件反射，下列做法错误的是（　）。
口诀快速上：要么同时（A ✓），要么先中性（B ✓ 二级，D ✓ 一级）。只有 C 是先无条件后中性——预告放饭后，无效。答案 C。
单选 · 例子分析
根据经典条件反射作用理论，铃声可以诱发狗的唾液分泌反应，则铃声是（　）。
第一步问的是铃声 → 刺激，排除 A、D（反射/反应）。第二步狗天生对铃声流口水吗？不 → 后天 → 条件。答案 C。
单选 · 例子分析
你闻到炒菜的香味直流口水，在这里，菜香和你分泌的口水分别是（　）。
香味是外界给的 → 刺激；流口水是你做的 → 反应/反射。先天后天？你闻香水也流口水吗？不会。你得吃过、知道好吃，再闻到才流 → 后天 → 条件。（为啥有人闻榴莲流口水有人不？因为吃过觉得好吃。）答案 B。
单选 · 拔高
当你看到菜单上的大扇贝时，你感到恶心，因为大扇贝曾经让你呕吐过。在这种情况下菜单上大扇贝的描述对你而言是（　）。
大扇贝是刺激（反应是恶心/呕吐），排除 C。天生看到扇贝就吐吗？不；题干还明说了「因为曾经让你呕吐过」→ 后天。答案 B。
真题 · 拔高（2024 年考过，老师觉得很简单但很多人错）
小陈一坐汽车就会晕车并伴随强烈呕吐；后来他一听说要坐汽车就开始呕吐。小陈的这种反应属于操作性条件反射。
「操作性」是斯金纳的词，强调反应在前刺激在后。考它大概率是拿来和经典性对比 → 看谁在前。「听说坐汽车」是外界给的 → 刺激在前；呕吐是他做的 → 反应在后。S→R → 这是经典性，不是操作性。答案 B。
真题 · 拔高
明朝的徐文长经常被叔叔无端责骂，于是他背着他人对着叔叔家的驴作揖，然后马上鞭打它。重复多次之后，驴一见他作揖就惊跳起来。能解释这一现象的理论是（　）。
看最后一句就够：驴是个体，「作揖」（鞠躬）是外界给的 → 刺激；「惊跳」是驴做的 → 反应。刺激在前 → 经典性。细看前面：作揖（中性）+ 鞭打（无条件刺激）→ 惊跳，重复多次 → 单独作揖也惊跳。这就是一级条件作用的建立过程。答案 C。
单选 · 拔高 2（需要推导，老师带着推了一遍）
当学生进考场或者当老师宣布即将举行考试时，学生感到非常焦虑，这可用经典条件作用理论的（　）来解释。
第一步进考场/宣布考试 = 刺激，焦虑 = 反应。题目讲的是刺激→反应的联结建立，没提「光给刺激不反应了」（消退），也没有两个相似刺激（泛化/分化）→ 排除 B、C。第二步天生进考场就焦虑吗？不 → 后天 → 是条件反射。那它是跟谁结合才建立的？推导：为什么进考场焦虑？大概率因为失败——「进考场 + 失败 → 焦虑」。第三步问：失败是无条件刺激还是条件刺激？小孩天天摔倒、吃不进饭，天生难受吗？不 → 失败也是后天才有感觉的 → 条件刺激。跟条件刺激结合建立 → 高级条件作用，答案 D。（这里的「失败」就相当于狗实验里的「铃声」。）
自己考自己（老师 151:32 的回顾）
实验叫什么？一级条件作用跟谁结合建立？二级又叫什么、跟谁结合？
狗进食摇铃实验；一级跟无条件刺激（先天有感觉的）结合；二级又叫高级条件作用，跟条件刺激（后天有感觉的，如铃声）结合。
建立顺序的口诀？为什么「先食物后铃声」不行？
要么先中性，要么和中性同时。因为铃声是预告，放在饭后就没有预告作用了。
「中性刺激一旦成为条件刺激，就可以作为无条件刺激」里的「作为」是什么意思？
替代。高级条件作用里，条件刺激（铃声）替代了无条件刺激（食物）的位置去和新的中性刺激结合。
无条件反射和条件反射怎么区分？举一个例子。
先天本能 vs 后天学习。食物→流口水是无条件；铃声→流口水是条件。
做巴甫洛夫题的两步是什么？
① 分刺激（外界给）和反应（个体做）；② 分先天（无条件）和后天（条件）。拔高再推导跟谁结合。
