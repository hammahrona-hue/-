第一 / 第二信号系统：有没有「说话」成语题专场

对应视频 133:04 ~ 145:41 · 幻灯片 S074 ~ S079

先听个故事：巴甫洛夫的弟弟

巴甫洛夫做狗实验时顺手拿弟弟也试了试：每次给食物就摇铃，后来弟弟一听铃声也流口水——说明人也有这种「听到声音就反应」的本事，人和动物都有，这叫第一信号系统。

但人比狗多了一样东西：语言。老师跟你描述一块提拉米苏——咖啡液泡的、上面有蓝莓、微苦带甜——你听完流口水了。这次刺激不是蛋糕本身，而是「话」。靠语言当中介引起的条件反射，叫第二信号系统，人独有——因为狗没有语言。

8.1 ~ 8.3两个信号系统（都是条件反射，都是大脑皮层功能）

第一信号系统

物理性的、具体的条件刺激：声、光、雷、电。
人 + 动物都有。
狗听铃流口水；人听铃回教室坐好。

VS

第二信号系统

以语言为中介的、抽象的条件刺激。
人特有。
语言有几种形式（了解即可，不考多选）：

  • 口头语言：谈虎色变、谈梅生津（谈 = 说）
  • 书面语言：看到「虎」字就害怕
  • 内部言语：一想到测验就焦虑（脑子里在说话，不是图片）
  • 交通语言（有争议，单独记）：司机看到红灯停车——因为从小学过「红灯停」，红灯有了意义
  • 其他：哑语、旗语
说人话

分不清「声光影电」？不要紧，只看有没有「语言」两个字：刺激是通过语言传给你的 → 第二；不是语言传的（一个声音、一个影子、一个图样）→ 第一。

8.4老师的三步判断法

坑 ①：不许加戏

题目没说的你不许延伸！杯弓蛇影里传给他的就是一个影子，有说话吗？没有。你不要在这说「哎呀我大脑里想到太可怕了」——那叫加戏。

判断第一还是第二，看的是刺激怎么传递给他——通过语言，还是通过一个图样。个体自己在那叭叭讲话没用。

坑 ②：典故不一定是第二

「望梅止渴」从字面看：望着梅子流口水，没人说话 → 第一。从典故看：曹操对士兵说「前方有梅林」，士兵口里生津 → 曹老板讲话了 → 第二。所以要看题目具体描述，不是看到典故就选第二。

8.5成语判定全表（老师课上逐个讲的）

例子刺激 → 反应先天/后天有语言？判定
迎风流泪风 → 流泪先天，谁被风吹都流—无条件反射（本能）
谈虎色变谈论老虎 → 脸色变后天（没见过老虎哪知道可怕）有（谈 = 说）第二
杯弓蛇影弓的倒影 → 害怕后天无（蛇和弓都不会说话）第一
尝梅生津梅子进嘴 → 流口水先天（吃东西不流口水噎死了）—无条件反射
望梅止渴（字面）看到梅子 → 流口水后天（没见过梅子不会流）无第一
望梅止渴（曹操典故）曹操说「前方有梅林」→ 生津后天有第二
闻过则喜听别人说自己的过错 → 高兴后天有（听闻别人讲）第二
闻鸡起舞鸡叫声 → 起床后天无（鸡不会说话，只是个声音）第一
导盲犬看红灯停下红灯 → 停后天动物，没语言第一
狗听主人叫名字跑过去名字声音 → 跑后天（练出来的）动物，没语言第一
学生一想到 / 听到要测验就焦虑想到测验 → 焦虑后天有（内部言语 / 口头）第二
纸鸢为羹（同学课后问的）看到大雁 → 打算做羹汤后天无（雁没跟他说话，只是视觉看到）第一
钩子

「进嘴」是本能，「看到」是第一，「谈 / 闻（听说）/ 想到」是第二，「动物」永远第一。

自测
「谈虎色变」和「杯弓蛇影」分别属于（　）。
谈虎 = 说话传递 → 第二；杯弓蛇影 = 看到影子、没人说话 → 第一。都是后天，不是本能。答案 B。
自测
「尝梅生津」属于（　）。
看清「尝」——已经放进嘴里了，吃东西流口水是本能，不用学。答案 A。老师说好多同学这个错了。
自己考自己
第一、第二信号系统的区别一句话？谁有？
第一：物理性刺激，人和动物都有；第二：以语言为中介，人特有。
判断的三步是什么？
① 先天→无条件反射；② 后天→看有无语言（有→第二，无→第一）；③ 动物后天只能是第一。
望梅止渴为什么可能是第一也可能是第二？
字面：望着梅子，没语言→第一；典故：曹操说前方有梅林，有语言→第二。看题目具体描述。
「一想到测验就焦虑」是哪种语言？
内部言语（大脑里在说话）→ 第二信号系统。
